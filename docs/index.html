DvorakJP lite
DvorakJP lite とは 導入方法 練習

DvorakJP lite とは

DvorakJP の拡張ローマ字入力のうち、QWERTY のローマ字入力と競合しないものだけを集めたローマ字テーブルです。

設計思想

  • QWERTY と共存する。 同じ変換表のまま、QWERTY ローマ字を今までどおりに打てます。 un.→うん。 enpou→えんぽう konbanha→こんばんは のような打ち方は変わりません。
  • QWERTY ローマ字で打たない列にだけ、拡張を割り当てる。 k' や c, は QWERTY ローマ字では打たないので、k'→かい、c,→こう のように使えます。
  • 衝突するものは採用しないか、別のキーに移す。 元祖 DvorakJP の n.(ねい) や nk(ぬん) は、QWERTY ローマ字の「ん＋次の音」と区別できません。 そこで な行 の拡張は、Dvorak 配列で n の真下にある v で打ちます（vj→ねん、v,→のう）。
  • 記号キーの置き場所を選べる。 「ア段＋い」は ' と - のどちらでも打てます（t' / t-→たい）。

拡張キー

キー意味例
' -ア段＋いs' さい
;ア段＋んs; さん
.エ段＋いs. せい
,オ段＋うs, そう
pウ段＋うsp すう
kウ段＋んsk すん
jエ段＋んsj せん
qオ段＋んsq そん
xイ段＋んsx しん

拗音にも使えます（ky, きょう、sh, しょう、jp じゅう）。 ぴゃ行だけは、Dvorak 配列で p と y が同じ手で打ちにくいため、h でも拗音になります（pha ぴゃ、ph, ぴょう、php ぴゅう）。 詳しい仕様は GitHub の README を見てください。

導入方法

ローマ字テーブルをダウンロード

1Google日本語入力のローマ字テーブルを更新する

  1. メニューバーの入力メニューから、Google日本語入力の「環境設定…」を開きます。
  2. 「一般」タブの「ローマ字テーブル」で「編集…」を押します。
  3. 左下の「編集」→「インポート…」で、ダウンロードした romantable_dvorakjplite.txt を選びます。
  4. 「OK」→「適用」で保存します。

2Dvorak 配列を追加する

  1. 「システム設定」→「キーボード」→「入力ソース」の「編集…」を開きます。
  2. 「＋」を押し、「英語」から「Dvorak」を追加します。
  3. Google日本語入力でかな入力をしたときも Dvorak 配列で打てるか確かめてください。

準備中

Windows での導入方法が確立できたら公開します。

Linux 版の Google日本語入力はないので、オープンソース版の Mozc（fcitx5-mozc など）を使います。ローマ字テーブルの形式は同じです。

1Mozc のローマ字テーブルを更新する

  1. Mozc の設定ツールを開きます。 
    /usr/lib/mozc/mozc_tool --mode=config_dialog
    ディストリビューションによっては /usr/libexec/mozc/mozc_tool にあります。
  2. 「一般」タブの「ローマ字テーブル」で「編集…」を押します。
  3. 左下の「編集」→「インポート…」で、ダウンロードした romantable_dvorakjplite.txt を選びます。
  4. 「OK」→「適用」で保存します。

2Dvorak 配列を追加する（fcitx5 の場合）

  1. fcitx5-configtool を開きます。
  2. 入力メソッドのグループで、キーボードレイアウトを「English (Dvorak)」にします。
  3. 同じグループに「Mozc」を追加します。Mozc はグループのレイアウトに従うので、かな入力も Dvorak 配列になります。
