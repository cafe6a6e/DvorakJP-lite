DvorakJP lite とは？

DvorakJP をご存じない方は、まずはDvorakJP の解説をご一読ください。

DvorakJP lite は、DvorakJP の効率的な拡張ローマ字入力の仕組みを維持しつつ、普通のローマ字入力を妨げないように見直した、いわば軽量版 DvorakJP です。打鍵数の削減につながらない拡張は削ぎ落としました。一般的なローマ字入力の打ち方に干渉せず、ご自身のペースで拡張ローマ字を徐々に取り入れられることを目指しています。

ローマ字テーブルの差替えだけで導入でき、Dvorak 配列の方はもちろん、QWERTY 配列の方でも気軽に試せます。

設計思想

1. 「ん」の後でも最小の打鍵数で打てるようにする

DvorakJP では、n の後の拡張キーが「な行拡張」になります（nj ねん、n. ねい、np ぬう）。また、nh は「にゃ行」の拗音です。そのため、母音の直後の「ん」に、これらのキーで始まる音が続くときは、n を 2 回打って「ん」を確定させる必要がありました。

DvorakJP lite では、な行拡張を v に移し、n の拗音拡張も使わないことで、この衝突を解消しました。そのため、DvorakJP では余計な打鍵が必要だった「ん」の後の入力も、通常のローマ字入力と同じ打鍵数で入力できます。

単語DvorakJPDvorakJP lite
鉛筆（えんぴつ）ennpitu（7 打。enpitu だと「えぬういつ」）enpitu（6 打）

全員は（ぜんいんは）zjinnha（7 打。zjinha だと「ぜんいにゃ」）zjinha（6 打）

そのうえで、拡張ルールを次の方針で見直しています。

  • 打鍵数を減らす拡張は、普通のローマ字で使わない組み合わせに移して残す。
    • な行拡張は n の代わりに、Dvorak 配列で n の真下にある v で打つ（vj ねん、v, のう）
    • ぴゃ行は、Dvorak 配列で p と y がどちらも左手の上段にあり、pya が同じ手の連続打鍵になって打ちにくい。そこで、h を使う拗音拡張のうち、右手の h を使って左右交互に打てる ph だけを採用する（pha ぴゃ、ph, ぴょう）。ph は普通のローマ字では使わない組み合わせなので、衝突しない
  • 打鍵数を減らさない拡張は、原則として採用しない。
    • ぴゃ行以外の h、n の拗音拡張は採用しない。この拡張は、y の代わりに使っても打鍵数は減らない（cna も cya も 3 打）が、拗音の子音と h・n を右手で続けて打てる（アルペジオ打鍵）という DvorakJP の工夫である。DvorakJP lite では、この利点よりも、普通のローマ字との互換性と覚えるルールの少なさを優先し、主要な拗音は QWERTY 同様「子音（右手）、y＋母音（左手）」で打つ。

2. QWERTY で身に付けたローマ字入力の規則をそのまま使える

拡張ルールを普通のローマ字で使わない組み合わせに限ったので、DvorakJP の拡張と共存しながら、かなを打つ一般的なローマ字のつづりはすべてそのまま使えます（z. … などの一部の記号入力は、拡張入力に使うため除きます）。

たとえば、「ん」を n 1 回で入力する（kanji → 漢字）といった、QWERTY で身に付けたローマ字入力の規則を覚え直す必要はありません。拡張入力を覚えなくても今までどおり入力でき、必要に応じて少しずつ拡張入力を取り入れられます。

3. 記号キーの自由度を担保する

「ア段＋い」は ' と - のどちらでも打てます（k' / k- → かい）。Dvorak 配列の上段左の記号キーは、好みで ' と - のどちらにしていても使えます。

4. 競合しない範囲で AZIK・gACT10 の短縮入力を採用する

DvorakJP のローマ字テーブルを軽量化した分、新たなカスタマイズの余地ができました。そこで実験的に、AZIK と gACT10 から、通常ローマ字や DvorakJP lite の拡張入力と競合しない拡張だけを採用し、さらに打鍵数を減らせるようにしています。

この短縮入力を含むローマ字テーブルは「DvorakJP lite ＋ 短縮拡張」版として配布します。実験中のため、予告なく変更することがあります。

DvorakJP lite の拡張キー

拡張キーは、子音や拗音のすぐ後に打って、二重母音や「ん」までをまとめて入力するキーです。たとえば「ア段＋い」の ' を s の後に打つと、s' で「さい」になります。
