DvorakJP lite
DvorakJP lite とは 導入方法 練習 補足：DvorakJP の解説

導入方法

お使いの OS とキーボード配列、短縮拡張の有無を選んで、下の導入手順に進んでください。

OS
キーボード配列

キー配列が QWERTY(JIS) の方向け。日本語入力は DvorakJP lite、英字直接入力は QWERTY(JIS) で入力できます。

キー配列が QWERTY(US) の方向け。日本語入力は DvorakJP lite、英字直接入力は QWERTY(US) で入力できます。

キー配列が Dvorak 配列の方向け。

短縮拡張

DvorakJP lite の拡張入力だけを採用します。

DvorakJP lite に AZIK・gACT10 由来の短縮入力を実験的に追加。仕様は変更される可能性があります。

ローマ字テーブルをダウンロード romantable_dvorakjplite_qwerty_jis.txt

Google日本語入力のローマ字テーブルをインポートする

  1. メニューバーの入力メニューから、Google日本語入力の「環境設定…」を開きます。
  2. 「一般」タブの「ローマ字テーブル」で「編集…」を押します。
  3. 左下の「編集」→「インポート…」で、ダウンロードした romantable_dvorakjplite_qwerty_jis.txt を選びます。
  4. 「OK」→「適用」で保存します。
  5. 同じ画面の「入力補助」タブの「自動変換」で、句読点（、。）での自動変換をオフにします（「読点」と「句点」のチェックを外すか、自動変換そのものをオフにします）。

理由：QWERTY 版では , と . を子音のキー（Dvorak 配列の w と v）として使います。自動変換がオンのままだと、, や . を打った時点でそれまでの文字が変換されてしまい、たとえば kqcr,s が「体重を」ではなく「体重、お」になります。

Google日本語入力のローマ字テーブルをインポートする

  1. タスクバーの入力モードのアイコン（「あ」や「A」）を右クリックし、「プロパティ」を開きます。
  2. 「一般」タブの「ローマ字テーブル」で「編集…」を押します。
  3. 左下の「編集」→「インポート…」で、ダウンロードした romantable_dvorakjplite_qwerty_jis.txt を選びます。
  4. 「OK」→「適用」で保存します。
  5. 同じ画面の「入力補助」タブの「自動変換」で、句読点（、。）での自動変換をオフにします（「読点」と「句点」のチェックを外すか、自動変換そのものをオフにします）。

Linux 版の Google日本語入力はないので、オープンソースの日本語入力システム Mozc（fcitx5-mozc など）を使います。ローマ字テーブルの形式は同じです。

Mozc のローマ字テーブルをインポートする

  1. Mozc の設定ツールを開きます。 
    /usr/lib/mozc/mozc_tool --mode=config_dialog
    ディストリビューションによっては /usr/libexec/mozc/mozc_tool にあります。
  2. 「一般」タブの「ローマ字テーブル」で「編集…」を押します。
  3. 左下の「編集」→「インポート…」で、ダウンロードした romantable_dvorakjplite_qwerty_jis.txt を選びます。
  4. 「OK」→「適用」で保存します。
  5. 同じ画面の「入力補助」タブの「自動変換」で、句読点（、。）での自動変換をオフにします（「読点」と「句点」のチェックを外すか、自動変換そのものをオフにします）。
