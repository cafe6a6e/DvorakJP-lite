DvorakJP lite
DvorakJP lite とは 導入方法 練習 補足：DvorakJP の解説

覚えた分だけ打鍵が減らせる、シンプルな拡張ローマ字テーブル

DvorakJP lite は、DvorakJP の効率的な拡張ローマ字入力の仕組みを維持しつつ、普通のローマ字入力を妨げないように見直した、いわば DvorakJP 拡張ローマ字テーブルの軽量版です。一般的なローマ字入力の打ち方に干渉せず、ご自身のペースで拡張ローマ字を徐々に取り入れられることを目指しています。

Google 日本語入力等のローマ字テーブルの差替えだけで導入でき、Dvorak 配列の方はもちろん、QWERTY 配列の方でも気軽に試せます。

DvorakJP lite の設計思想

DvorakJP をご存じない方は、DvorakJP の解説をぜひご一読ください。

1. 通常ローマ字の最短打鍵法をそのまま使える

DvorakJP では、n の後の拡張キーが「な行拡張」（例：nj ねん、n. ねい、np ぬう）、nh が「にゃ行」の拗音となります。そのため、これらのキーが続くときは、通常ローマ字のように「n＋子音」で n を「ん」に確定することができません。結果、通常ローマ字では 1 打で打てた n を、あえて 2 打して「ん」を確定させるケースが生じてしまいます。

この通常ローマ字とのルール衝突を避け、かつ拡張ルールをシンプルにするために、次の方針で見直しました。

  • 方針 1｜打鍵数を減らす拡張は残す。普通のローマ字と衝突するものだけ、使わない組み合わせに移す。
    • 二重母音、撥音（ん）拡張は、な行拡張を除いて、そのまま採用する。
    • な行拡張の子音は n ではなく、Dvorak 配列で n の真下にある v で打つ（vj ねん、v, のう）。
  • 方針 2｜打鍵数を減らさない拡張は、同指連続打鍵を減らす効果が特に高い「きゃ行・ぴゃ行」の拗音拡張だけを採用する。
    • きゃ行・ぴゃ行は、Dvorak 配列で k・p・y がすべて左手の人差し指にあり、kyu・pyu などが同じ指の連続打鍵になって特に打ちにくい。そこで、右手のキーと左右交互に打てる cy・ph を「きゃ行・ぴゃ行」の拗音として採用する。
    • それ以外の h・n の拗音拡張（DvorakJP の解説）は採用しない。この拡張は、y の代わりに使っても打鍵数は減らない。打鍵数に寄与しないルールを削ぎ、拡張ルールをシンプルに保つことを優先した。ほかの拗音は QWERTY 同様「子音（右手）、y＋母音（左手）」で打つ。

その結果、「ん」の後も通常のローマ字入力と同じ打鍵数で入力できます。

2. 記号キーの自由度を担保する

「ア段＋い」は ' と - のどちらでも打てます（k' / k- → かい）。Dvorak 配列の上段左の記号キーは、好みで ' と - のどちらにしていても使えます。

3. 競合しない範囲で AZIK・gACT10 の短縮入力を採用する

DvorakJP のローマ字テーブルを軽量化した分、新たなカスタマイズの余地ができました。そこで実験的に、AZIK と gACT10 から、通常ローマ字や DvorakJP lite の拡張入力と競合しない拡張だけを採用し、さらに打鍵数を減らせるようにしています。

この短縮入力を含むローマ字テーブルは「DvorakJP lite ＋ 短縮拡張」版として配布します。実験中のため、予告なく変更することがあります。

DvorakJP lite の拡張キー

拡張キーは、子音や拗音のすぐ後に打って、二重母音や「ん」までをまとめて入力するキーです。たとえば「ア段＋い」の ' を s の後に打つと、s' で「さい」になります。

比較2: 同指連続打鍵率

同指連続打鍵率を以下で定義します。値が小さいほど、同じ指で続けて打つことが少なく、指の負担が少ないことを示します。

同指連続打鍵率= 直前と同じ指で打つ打鍵数 打鍵数

ここで、日本語文での打鍵数は、ローマ字テーブルでの最短の打ち方で数えます。最短の打ち方が複数あるときは、同指打鍵が最も少ないもので数えます。

直前と同じ指で打つ打鍵は、別のキーを打つ同指異キー（QWERTY の yu など）と、同じキーを続けて打つ同指同キー（促音の tt など）に分けて示します。
