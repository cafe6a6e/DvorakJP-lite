# DvorakJP lite

[DvorakJP](https://cafe6a6e.github.io/DvorakJP-lite/#dvorakjp) の拡張ローマ字入力を、普通のローマ字入力を妨げないように見直し、**「ん」の後も余計な打鍵なしで打てる**ようにしたローマ字テーブルです。

たとえば「鉛筆（えんぴつ）」は、DvorakJP では `ennpitu` と `n` を 2 回打つ必要がありますが、DvorakJP lite では `enpitu` と 1 打少なく打てます。DvorakJP の二重母音や「ん」の拡張の仕組みは引き継ぎ（な行の拡張は `v` に移しています）、QWERTY で身に付けたローマ字入力の規則もそのまま使えるので、今までの打ち方を覚え直す必要もありません。

また、実験的な試みとして、[AZIK](https://note.com/actbemu/n/n74f1c04c9a2e) の特殊拡張を、普通のローマ字や DvorakJP lite の拡張と競合しない範囲で採用し、打鍵数をさらに減らせるようにしています（[設計思想の 4](#4-実験的共存できる範囲で-azik-の短縮入力を採用する)）。

**公式ページ: https://cafe6a6e.github.io/DvorakJP-lite/** （導入方法・タイピング練習）

![DvorakJP lite のキー配置と拡張キー](docs/images/layout.webp)

## 設計思想

### 1. 「ん」の後でも最小の打鍵数で打てるようにする

DvorakJP では、`n` の後の拡張キーが「な行の拡張」になります（`nj` ねん、`n.` ねい、`np` ぬう）。また、`nh` は「にゃ行」の拗音です。そのため、母音の直後の「ん」に、これらのキーで始まる音が続くときは、`n` を 2 回打って「ん」を確定させる必要がありました。

DvorakJP lite では、な行の拡張を `v` に移し、`n` の拗音の拡張も使わないことで、この衝突をなくしました。そのため、DvorakJP では余計な打鍵が必要だった「ん」の後の入力も、通常のローマ字入力と同じ打鍵数で入力できます。

| 単語 | DvorakJP | DvorakJP lite |
|---|---|---|
| 鉛筆（えんぴつ） | `ennpitu`（7 打。`enpitu` だと「えぬういつ」） | `enpitu`（6 打） |
| 温情（おんじょう） | `onnj,`（5 打。`onj,` だと「おねん、」） | `onj,`（4 打） |
| 隠蔽（いんぺい） | `innp.`（5 打。`inp.` だと「いぬう。」） | `inp.`（4 打） |
| 全員は（ぜんいんは） | `zjinnha`（7 打。`zjinha` だと「ぜんいにゃ」） | `zjinha`（6 打） |

そのうえで、拡張ルールを次の方針で見直しています。

- **打鍵数を減らす拡張は、普通のローマ字で使わない組み合わせに移して残す。**
  - な行の拡張は `n` の代わりに、Dvorak 配列で `n` の真下にある `v` で打つ（`vj` ねん、`v,` のう）
  - ぴゃ行は、Dvorak 配列で `p` と `y` がどちらも左手の上段にあり、`pya` が同じ手の連続打鍵になって打ちにくい。そこで、`h` を使う拗音拡張のうち、右手の `h` を使って左右交互に打てる `ph` だけを採用する（`pha` ぴゃ、`ph,` ぴょう）。`ph` は普通のローマ字では使わない組み合わせなので、衝突しない
- **打鍵数を減らさない拡張は、原則として採用しない。**
  - ぴゃ行以外の `h`、`n` の拗音拡張は採用しない。この拡張は、`y` の代わりに使っても打鍵数は減らない（`cna` も `cya` も 3 打）が、拗音の子音と `h`・`n` を右手で続けて打てる（アルペジオ打鍵）という DvorakJP の工夫である。DvorakJP lite では、この利点よりも、普通のローマ字との互換性と覚えるルールの少なさを優先し、主要な拗音は QWERTY 同様「子音（右手）、`y`＋母音（左手）」で打つ。

### 2. QWERTY で身に付けたローマ字入力の規則をそのまま使える

拡張ルールを普通のローマ字で使わない組み合わせに限ったので、DvorakJP の拡張と共存しながら、かなを打つ一般的なローマ字のつづりはすべてそのまま使えます（`z.` … などの一部の記号入力は、拡張入力に使うため除きます）。

たとえば、「ん」を `n` 1 回で入力する（`kanji` → 漢字）といった、QWERTY で身に付けたローマ字入力の規則を覚え直す必要はありません。拡張入力を覚えなくても今までどおり入力でき、必要に応じて少しずつ拡張入力を取り入れられます。

### 3. 記号キーの自由度を担保する

「ア段＋い」は `'` と `-` のどちらでも打てます（`k'` / `k-` → かい）。Dvorak 配列の上段左の記号キーは、好みで `'` と `-` のどちらにしていても使えます。

QWERTY 版では、キーの位置が決まっているので `'` の位置のキーだけにしています（[QWERTY 版](#qwerty-版)）。

### 4. （実験的）共存できる範囲で AZIK の短縮入力を採用する

[AZIK](https://note.com/actbemu/n/n74f1c04c9a2e) の短縮入力のうち、普通のローマ字や DvorakJP lite の拡張入力とぶつからないものだけを、実験的に採用しています。「こと」を `kt`、「です」を `ds` のように、よく出る 2 文字を子音 2 つで打てます。`k` で始まるものは、か行と同じく `c` でも打てます。使わなくても、今までどおりの打ち方で入力できます。

あわせて、AZIK にはない DvorakJP lite 独自の短縮入力（「れば」を `rb`、「くだ（さい）」を `kd` または `cd` など 10 種類）も、コーパスで効果を確かめたうえで実験的に追加しています。

## DvorakJP との差分サマリ

| ルール | DvorakJP | DvorakJP lite | 補足 |
|---|---|---|---|
| **か行** | `ca` `ci` `cu` `ce` `co` | 維持 | |
| **きゃ行** | `cna` `cnu` `cno`（`kha` 系も可） | `cya` `cyu` `cyo` | h/n 拗音拡張に依存しないため。DvorakJP では `cya` = ちゃ なので意味が異なる |
| **な行＋二重母音** | `n'` `np` `n.` `n,` | `v'` `vp` `v.` `v,` | 出現頻度の低い「ゔぁ行＋二重母音」拡張入力は犠牲にする |
| **な行＋ん** |`n;` `nx` `nk` `nj` `nq` | `v;` `vx` `vk` `vj` `vq` | 出現頻度の低い「ゔぁ行＋ん」拡張入力は犠牲にする |
| **h拗音拡張** | `ph*` `rh*` `nh*` `zh*` etc. | `ph*` のみ採用 | Dvorak 配列で `y` 拗音では打ちにくい「ぴゃ行」に対処する。`nh*` は QWERTY の「ん＋は行」、`zh*` は `zh`(←) と衝突する |
| **n拗音拡張** | `bn*` `hn*` `tn*` `mn*` `gn*` `cn*` etc. | 不採用 | 打鍵数は `y` と同じで、普通のローマ字との互換性と覚えるルールの少なさを優先する |
| **ア段＋い** | `'` のみ | `'` と `-` | 記号キーの自由度を担保する |
| **z 記号** | `z.` `z,` `zj` `zk` が記号と拡張で重複 | 拡張（ぜい・ぞう・ぜん・ずん）を採用 | 衝突する記号は削除し、記号は `;` で打つ |
| **てぃ行** | `th*` `dh*`（`thx` てぃん など） | 採用 | 「ミーティング」「エンディング」などの てぃん・でぃん を 1 打少なく打てる。`th` `dh` は普通のローマ字でも てゃ行・でゃ行なので、衝突しない |
| **AZIK の短縮入力（実験的）** | なし | AZIK 由来 21 種類（`kt` こと、`ds` です など）と lite 独自 10 種類（`rb` れば、`kd` くだ など）。`k` で始まるものは `c` も可 | 普通のローマ字や lite の拡張とぶつからないものだけを採用する |
| **その他の拡張** | 小書き・くぁ行・すぁ行・つぁ行・とぁ行・うぁ行・ふゃ行・ゔ行などの拡張 | 不採用 | 使用頻度が低いため採用しない |
| **`qu`** | くぅ | く | Google 標準に合わせる |

## 記号仕様

記号は `;` で打ちます。Google 標準の z 記号のうち、拡張と衝突するもの（`z-` `z,` `z.` `zk` `zj`）は削除しました。

| 記号 | `;` で打つ | z 記号（Google 標準） |
|---|---|---|
| 〜 | `;-` | 削除（`z-` は ざい） |
| ・ | `;/` | `z/` |
| ‥ | `;,` | 削除（`z,` は ぞう） |
| … | `;.` | 削除（`z.` は ぜい） |
| 『 | `;[` | `z[` |
| 』 | `;]` | `z]` |
| ← | `;d` | `zh` |
| → | `;n` | `zl` |
| ↑ | `;t` | 削除（`zk` は ずん） |
| ↓ | `;h` | 削除（`zj` は ぜん） |

## QWERTY 版

OS のキー配列を QWERTY のままにして、Dvorak 配列と同じ位置のキーで DvorakJP lite を打つための表です。JIS 配列用と US 配列用があります。

### キーの対応

| 段 | Dvorak | QWERTY(US) | QWERTY(JIS) |
|---|---|---|---|
| 数字段の右 | `[` `]` | `-` `=` | `-` `^` |
| 上段 | `' , . p y f g c r l / =` | `q w e r t y u i o p [ ]` | `q w e r t y u i o p @ [` |
| ホーム段 | `a o e u i d h t n s -` | `a s d f g h j k l ; '` | `a s d f g h j k l ; :` |
| 下段 | `; q j k x b m w v z` | `z x c v b n m , . /` | `z x c v b n m , . /` |

例: `iq`（Dvorak の `c'`）→ かい、`kq`（`t'`）→ たい、`;jw`（`sh,`）→ しょう。US 版と JIS 版の違いは、記号キー 3 つ（`'`/`:`、`=`/`^`、`[`/`@`）だけです。

### Dvorak 版との違い

Dvorak 版を同じ位置のキーに置き換えたうえで、次の点を変えています。

| 項目 | Dvorak 版 | QWERTY 版 | 理由 |
|---|---|---|---|
| **ア段＋い** | `'` と `-` | `'` の位置のキーだけ（`iq` かい） | キーの位置が決まっているので、2 通りにする必要がない |
| **記号** | `;` と一部の `z`（`z/` `z[` `z]` `zh` `zl`） | `;` の位置のキーだけ（`z[` ・、`zh` ← など。JIS は `z@` ・） | 打ち方を 1 通りにする |
| **てぃ・とぅ・てゅ など** | `t'i` `t'u` `t'yu` `d'i` `d'u` `d'yu` | なし（標準の `thi` などで打つ。てぃん・でぃん は `thx` `dhx` の位置のキー） | `t'` たい・`d'` だい を、次のキーを待たずに確定させる |
| **ー** | `-` | `-` の位置のキー（US `'`、JIS `:`）と、`'` の位置のキー（`q`） | `q` 単独でも打てるようにする |
| **右下のキー** | — | ざ行（Dvorak の `z`）は `/` でも `-` でも打てる（`/a` / `-a` ざ） | 右下のキーが `/` ではなく `-` のキーボードでも打てるようにする |
| **点の記号** | — | 普通のローマ字と同じ `z.` …、`z,` ‥、`z/` ・ も打てる（`;` の位置のキーで打つ `ze` `zw` `z[` も使える） | QWERTY のローマ字に慣れた打ち方でも打てるようにする |

### 注意

- **句読点での自動変換をオフにしてください。** QWERTY 版では `,` と `.` を子音（Dvorak の `w` と `v`）として使います。Google 日本語入力の「入力補助」→「自動変換」で読点・句点の自動変換がオンになっていると、`,` や `.` を打った時点でそれまでの文字が変換されてしまいます（例: `kqcr,s` が「体重を」ではなく「体重、お」になる）。
- **`-` は「「」とざ行の両方に使います。** `-` 単独は「「」ですが、直後にざ行の続き（`a` など）を打つと、ざ行として読まれます（`-a` は「「あ」ではなく「ざ」）。
- **中黒「・」は `z/` か `z[`（JIS は `z@`）で打ちます。** 普通の QWERTY ローマ字の `/` 単独は、ざ行の子音として使っているので使えません。

### 作り方

QWERTY 版の表は、Dvorak 版から `bun run build:qwerty` で作ります。手で編集しないでください。手順は `docs/keymap.js` の `buildQwertyTable` にあります。

1. Dvorak 版を簡単にする（`simplifyForQwerty`。上の「Dvorak 版との違い」のうち、ア段＋い・記号・てぃ など・ー）。
2. 入力の文字を、同じ位置にある QWERTY の文字に置き換える（`convertTable`）。
3. Dvorak の `z` を含む行ごとに、`/` を `-` に置き換えた行を足す。
4. 点の記号（`z.` `z,` `z/`）を、同じ記号を `;` の位置のキーで打つ行のすぐ後に足す。
