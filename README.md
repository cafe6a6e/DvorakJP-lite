# DvorakJP lite

DvorakJP 拡張ローマ字入力のうち、**QWERTY ローマ字入力と競合しないもの**だけを追加した、ローマ字変換表です。

**公式ページ: https://cafe6a6e.github.io/DvorakJP-lite/** （導入方法・タイピング練習）

![DvorakJP lite のキー配置と拡張キー](docs/images/layout.webp)

## 設計思想

### 1. QWERTY と共存する

元祖 DvorakJP の拡張ルールの一部は、QWERTY ローマ字の「ん」の打ち方と衝突します。

| 打鍵 | QWERTY ローマ字 | 元祖 DvorakJP |
|---|---|---|
| `un.` | うん。 | うねい |
| `enpou` | えんぽう | えぬうおう |
| `konbanha` | こんばんは | こんばにゃ |

DvorakJP lite では、衝突する拡張ルールを次の方針で扱い、QWERTY ローマ字の打ち方を一切変えません。

- **効果の大きいものは、QWERTY ローマ字で打たない組み合わせを最小限使って採用する。** 例:
  - な行の拡張は `n` の代わりに、Dvorak 配列で `n` の真下にある `v` で打つ（`vj` ねん、`v,` のう）
  - ぴゃ行は、Dvorak 配列で `p` と `y` が同じ手で打ちにくいので、h による拗音のうち `ph` だけを採用する（`pha` ぴゃ、`ph,` ぴょう）
- **効果が限定的なものは採用しない。** 例:
  - ぴゃ行以外の`h`,`n`拗音拡張は採用しない。主要な拗音は、QWERTY 同様「子音（右手）、`y`＋母音（左手）」で打つ。

### 2. 記号キーの自由度を担保する

「ア段＋い」は `'` と `-` のどちらでも打てます（`k'` / `k-` → かい）。Dvorak 配列の上段左の記号キーは、好みで `'` と `-` のどちらにしていても使えます。

## DvorakJP との差分サマリ

| ルール | DvorakJP | DvorakJP lite | 補足 |
|---|---|---|---|
| **か行** | `ca` `ci` `cu` `ce` `co` | 維持 | |
| **きゃ行** | `cna` `cnu` `cno`（`kha` 系も可） | `cya` `cyu` `cyo` | h/n 拗音拡張に依存しないため。元祖では `cya` = ちゃ なので意味が異なる |
| **な行＋二重母音** | `n'` `np` `n.` `n,` | `v'` `vp` `v.` `v,` | 出現頻度の低い「ゔぁ行＋二重母音」拡張入力は犠牲にする |
| **な行＋ん** |`n;` `nx` `nk` `nj` `nq` | `v;` `vx` `vk` `vj` `vq` | 出現頻度の低い「ゔぁ行＋ん」拡張入力は犠牲にする |
| **h拗音拡張** | `ph*` `rh*` `nh*` `zh*` etc. | `ph*` のみ採用 | Dvorak 配列で `y` 拗音では打ちにくい「ぴゃ行」に対処する。`nh*` は QWERTY の「ん＋は行」、`zh*` は `zh`(←) と衝突する |
| **n拗音拡張** | `bn*` `hn*` `tn*` `mn*` `gn*` `cn*` etc. | 不採用 | メリットが薄いため採用しない |
| **ア段＋い** | `'` のみ | `'` と `-` | 記号キーの自由度を担保する |
| **z 記号** | `z.` `z,` `zj` `zk` が記号と拡張で重複 | 拡張（ぜい・ぞう・ぜん・ずん）を採用 | 衝突する記号は削除し、記号は `;` で打つ |
| **その他の拡張** | 小書き・くぁ行・すぁ行・つぁ行・とぁ行・てぃ行・うぁ行・ふゃ行・ゔ行などの拡張 | 不採用 | 使用頻度が低いため採用しない |
| **`qu`** | くぅ | く | Google 標準に合わせる |

## 拡張仕様

### 拡張キー

子音の後に、母音の代わりに下のキーを打ちます。

| キー | 意味 | 直音の例 | な行の例 | 拗音の例（きゃ行・ぴゃ行） |
|---|---|---|---|---|
| `'` または `-` | ア段＋い | `s'` `s-` さい | `v'` `v-` ない | `cy'` `cy-` きゃい、`ph'` `ph-` ぴゃい |
| `;` | ア段＋ん | `s;` さん | `v;` なん | `cy;` きゃん、`ph;` ぴゃん |
| `.` | エ段＋い | `s.` せい | `v.` ねい | `cy.` きぇい、`ph.` ぴぇい |
| `,` | オ段＋う | `s,` そう | `v,` のう | `cy,` きょう、`ph,` ぴょう |
| `p` | ウ段＋う | `sp` すう | `vp` ぬう | `cyp` きゅう、`php` ぴゅう |
| `k` | ウ段＋ん | `sk` すん | `vk` ぬん | `cyk` きゅん、`phk` ぴゅん |
| `j` | エ段＋ん | `sj` せん | `vj` ねん | `cyj` きぇん、`phj` ぴぇん |
| `q` | オ段＋ん | `sq` そん | `vq` のん | `cyq` きょん、`phq` ぴょん |
| `x` | イ段＋ん | `sx` しん | `vx` にん | `cyx` きぃん、`phx` ぴぃん |

子音とキーが同じ文字になる組み合わせ（`kk` `pp` `jj` など）は、促音「っ」のままです。くん は `ck`、じぇん は `jyj` で打ちます。ぷう は拡張では打てないので `puu` と打ちます。

### 直音

- 対象の子音: `k` `c` `g` `s` `z` `t` `d` `h` `b` `p` `m` `r` `y` `w` `f`
- や行は `y'` やい、`y;` やん、`yp` ゆう、`yk` ゆん、`y,` よう、`yq` よん、`y.` いぇい、`yj` いぇん です。
- わ行は `w'` わい、`w;` わん、`wp` うう、`wk` うん、`w.` うぇい、`wj` うぇん、`wx` うぃん です。
- ふぁ行は `f'` ふぁい、`fp` ふう、`fk` ふん などです。

### 拗音

- `y` 系（`ky` `gy` `sy` `zy` `jy` `ty` `dy` `cy` `hy` `by` `py` `my` `ry` `ny`）と、`sh` `ch` `j` に拡張キーを付けます。
  例: `ky,` きょう、`syp` しゅう、`sh,` しょう、`j,` じょう、`jp` じゅう、`ch,` ちょう、`nyp` にゅう
- `sh` `sy` `ch` `j` に `x` を付けると、しん・ちん・じん になります。他の拗音に `x` を付けると、きぃん のようになります。
- **h や n を使う拡張拗音（`kh*` `cn*` `nh*` など）は、`ph`（ぴゃ行）を除いて入れません。**

### な行拡張は `v` で打つ

`v` は Dvorak 配列で `n` の真下（同じ薬指で1段下）にあります。

| `v'` `v-` | `v;` | `vx` | `vp` | `vk` | `v.` | `vj` | `v,` | `vq` |
|---|---|---|---|---|---|---|---|---|
| ない | なん | にん | ぬう | ぬん | ねい | ねん | のう | のん |

- ゔ行（`va` `vi` `vu` `ve` `vo` `vy*`）は Google 標準のままです。そのため、ゔ行の拡張（ゔぁい など）は入れていません。
- にゃ行の拡張は `n` のまま打てます（`nyp` にゅう、`ny,` にょう など）。

### その他の変更点（lite 独自）

- `c` で か行 を打てます（`ca` か、`ci` き、`ce` け、`cya` きゃ）。Google 標準の `ci`=し、`ce`=せ、`cya`=ちゃ とは異なります。
- `qu` は く です。
- 記号は `;` で打ちます: `;-` 〜、`;,` ‥、`;.` …、`;[` 『、`;]` 』、`;d` ←、`;n` →、`;t` ↑、`;h` ↓。
- Google 標準の z 記号のうち、拡張と衝突する `z.` `z,` `zj` `zk` `z-` は削除しました（これらはそれぞれ ぜい・ぞう・ぜん・ずん・ざい になります）。`z/` `z[` `z]` `zh` `zl` は残っています。
